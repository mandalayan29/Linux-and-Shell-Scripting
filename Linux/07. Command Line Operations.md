# Command Line Operations: A Complete Tutorial Guide

## Introduction

Welcome to this comprehensive tutorial on Linux command line operations! This guide will teach you how to:

- Use the command line for system operations
- Search for files
- Create and manage files
- Install and update software

Linux system administrators spend a significant amount of time at the command line. There's a saying:

> **"Graphical user interfaces make easy tasks easier, while command line interfaces make difficult tasks possible."**

---

## Part 1: Why Use the Command Line?

### Advantages of the Command Line

| Advantage | Description |
|-----------|-------------|
| **No GUI Overhead** | Runs faster, uses fewer resources |
| **Complete Control** | Virtually every task can be accomplished |
| **Scripting** | Automate often-used or complex tasks |
| **Remote Access** | Sign into machines anywhere on the internet |
| **Launch Applications** | Start GUI apps from command line |
| **Consistency** | Works the same across all distributions |

### Command Line vs Graphical Interface

| Aspect | Command Line | Graphical Interface |
|--------|--------------|---------------------|
| **Speed** | Fast (no overhead) | Slower (GUI overhead) |
| **Learning Curve** | Steeper | Easier |
| **Remote Access** | Excellent (SSH) | Limited (VNC) |
| **Scripting** | Full support | Limited |
| **Consistency** | Same everywhere | Varies by distro |

## Part 3: Basic Command Syntax

### Command Structure

Most commands follow this pattern:

```
command [options] [arguments]
```

| Element | Description | Example |
|---------|-------------|---------|
| **Command** | The program name | `ls` |
| **Options** | Modify behavior (start with - or --) | `-l`, `--help` |
| **Arguments** | What the command operates on | `/home` |

### Examples

```bash
# Basic command (no options, no arguments)
ls

# Command with option
ls -l

# Command with option and argument
ls -l /home

# Command with multiple options
ls -la /home
```

### Common Option Types

| Type | Example | Description |
|------|---------|-------------|
| **Short Option** | `-l` | Single dash, single letter |
| **Short Option with Value** | `-f filename` | Option followed by value |
| **Long Option** | `--help` | Two dashes, word |
| **Long Option with Value** | `--file=filename` | Equals sign |

## Part 4: Basic File Viewing Commands

### cat - Concatenate Files

**Purpose:** Display file contents on screen

**Syntax:**
```bash
cat [options] [filename]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-n` | Show line numbers |
| `-b` | Number non-blank lines |
| `-s` | Squeeze multiple blank lines |

**Examples:**
```bash
# Display file content
cat file.txt

# Display with line numbers
cat -n file.txt

# Combine multiple files
cat file1.txt file2.txt > combined.txt
```

### head - Show First Lines

**Purpose:** Display first few lines of a file

**Syntax:**
```bash
head [options] [filename]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-n N` | Show first N lines (default 10) |
| `-c N` | Show first N bytes |

**Examples:**
```bash
# Show first 10 lines (default)
head file.txt

# Show first 20 lines
head -n 20 file.txt

# Show first 100 bytes
head -c 100 file.txt
```

### tail - Show Last Lines

**Purpose:** Display last few lines of a file

**Syntax:**
```bash
tail [options] [filename]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-n N` | Show last N lines (default 10) |
| `-f` | Follow file (watch for changes) |
| `-F` | Follow with retry |

**Examples:**
```bash
# Show last 10 lines (default)
tail file.txt

# Show last 20 lines
tail -n 20 file.txt

# Watch a log file in real-time
tail -f /var/log/syslog
```

### less - Page Through Files

**Purpose:** View files page by page

**Syntax:**
```bash
less [options] [filename]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-N` | Show line numbers |
| `-S` | Chop long lines (no wrap) |

**Navigation Keys in less:**

| Key | Action |
|-----|--------|
| `Space` | Next page |
| `b` | Previous page |
| `Enter` | Next line |
| `g` | Go to top |
| `G` | Go to bottom |
| `/pattern` | Search forward |
| `?pattern` | Search backward |
| `q` | Quit |

**Examples:**
```bash
# View file page by page
less file.txt

# View with line numbers
less -N file.txt
```

### tac - Reverse File Display

**Purpose:** Display file lines in reverse order (cat backwards)

**Syntax:**
```bash

```

**Example:**

## Part 6: Path Names

### Absolute Paths

An **absolute path** starts from the root directory (`/`) and follows the tree to the target.

**Characteristics:**
- Always starts with `/`
- Complete path from root
- Works from any location

**Examples:**
```bash
/home/student/Documents
/etc/nginx/nginx.conf
/usr/bin/ls
```

### Relative Paths

A **relative path** starts from the current working directory.

**Characteristics:**
- Does NOT start with `/`
- Uses `.` and `..` for navigation
- Shorter, less typing

**Examples:**
```bash
Documents/           # Current directory → Documents
../var/log           # Parent directory → var → log
./script.sh          # Current directory → script.sh
```

### Path Navigation Example

```bash
# Current location: /home/student
$ pwd
/home/student

# Absolute path
$ cd /usr/local/bin

# Relative path (from /usr/local/bin back to home)
$ cd ../../home/student

# Using shortcuts
$ cd ~/Documents     # Home directory → Documents
$ cd /etc            # Root → etc
$ cd ..              # Go up one level
```

### Multiple Slashes

Linux ignores extra slashes:
```bash
# All of these are equivalent:
/usr/local/bin
//usr//local///bin
/usr/local/bin/
```

**Common Options:**

**Purpose:** Remove empty directories

**Syntax:**
```bash

```

**Note:** Directory must be empty, or command fails.

**Examples:**
```bash
# Remove empty directory
rmdir mydir

# Remove multiple empty directories

```

### rm - Remove Files/Directories

**Purpose:** Remove files and directories

**Syntax:**
```bash
rm [options] target
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-i` | Interactive (prompt before delete) |
| `-f` | Force (no prompts) |
| `-r` | Recursive (remove directories and contents) |
| `-v` | Verbose |

**Examples:**
```bash
# Remove a file

# Remove with confirmation
rm -i file.txt
```

- `rm -rf /` - Will wipe your entire system!

## Part 9: Wildcards and Globbing

### What are Wildcards?

Wildcards are special characters that match patterns in filenames.

| Wildcard | Matches | Example |
|----------|---------|---------|
| `*` | Any string | `*.txt` matches all .txt files |
| `?` | Single character | `file?.txt` matches file1.txt, file2.txt |
| `[ ]` | Set of characters | `file[0-9].txt` matches file0.txt..file9.txt |
| `[^ ]` | Characters NOT in set | `file[^0-9].txt` matches filea.txt |

### Using Wildcards

**Examples:**
```bash
# All .txt files
ls *.txt

# Files starting with "file"
ls file*

# Files with one character before .txt
ls file?.txt

# Files with numbers
ls [0-9]*.txt

# Files with letters
ls [a-zA-Z]*.txt

# All except .txt files
ls *.[!t][!x][!t]
```

### Quoting and Wildcards

**Important:** Quotes prevent wildcard expansion.

```bash
# Without quotes - wildcard expands
apt search vmware*    # Expands to files in current directory

# With quotes - wildcard passes to command
apt search "vmware*"  # Searches for packages starting with "vmware"
```

## Part 10: Finding Files

### locate - Fast File Search

**Purpose:** Find files using a database

**Syntax:**
```bash
locate [options] pattern
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-i` | Case insensitive |
| `-n N` | Limit results to N matches |

**Examples:**
```bash
# Find files containing "ssh"
locate ssh

# Case insensitive search
locate -i file

# Limit results
locate -n 5 .conf
```

**How `locate` Works:**
1. Database created by `updatedb`
2. Run automatically daily
3. Search is very fast
4. Database must be updated for new files

**Update locate Database:**
```bash
# Update database (as root)
sudo updatedb
```

### find - Powerful File Search

**Purpose:** Search for files with extensive criteria

**Syntax:**
```bash
find [path] [expression]
```

**Common Search Criteria:**

| Option | Description |
|--------|-------------|
| `-name` | Match filename (case sensitive) |
| `-iname` | Match filename (case insensitive) |
| `-type` | File type (f=file, d=directory, l=link) |
| `-size` | File size |
| `-mtime` | Modified time (days) |
| `-atime` | Accessed time (days) |
| `-user` | Owner username |
| `-perm` | Permissions |

**Examples:**
```bash
# Find all files in current directory
find .

# Find files named "gcc"
find / -name gcc

# Find only directories named "gcc"
find / -name gcc -type d

# Find only regular files named "gcc"
find / -name gcc -type f

# Find files larger than 10MB
find / -size +10M

# Find files modified in last 7 days
find / -mtime -7

# Find files modified exactly 7 days ago
find / -mtime 7

# Find files modified more than 30 days ago
find / -mtime +30

# Find files newer than reference file
find . -newer reference.txt
```

**File Size Specifications:**

| Suffix | Meaning |
|--------|---------|
| `c` | Bytes |
| `k` | Kilobytes |
| `M` | Megabytes |
| `G` | Gigabytes |

### Running Commands with find

**Using `-exec` to Run Commands:**

**Syntax:**
```bash
find [criteria] -exec command {} \;
```

**Examples:**
```bash
# Find and remove .swp files
find . -name "*.swp" -exec rm {} \;

# Find and list all files
find . -type f -exec ls -l {} \;

# Find and remove files with confirmation
find . -name "*.tmp" -ok rm {} \;
```

**Understanding `-exec`:**
- `{}` - Placeholder for found files
- `\;` - End of command (must be escaped)
- `-ok` - Prompt before executing

### find vs locate

| Feature | locate | find |
|---------|--------|------|
| **Speed** | Very fast | Slow (searches in real-time) |
| **Database** | Uses database | No database |
| **Freshness** | Only as good as last update | Always current |
| **Criteria** | Limited | Extensive |
| **Actions** | None | Can run commands |

## Part 11: Links

### What are Links?

**Hard Links:**
- Multiple names for same file
- Same inode number
- Saves disk space
- Cannot cross file systems

**Soft/Symbolic Links:**
- Point to another file
- Different inode number
- Can cross file systems
- Can point to directories
- Can have dangling links

### ln - Create Links

**Syntax:**
```bash
ln [options] target link_name
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-s` | Create symbolic (soft) link |
| `-f` | Force (overwrite existing) |

### Hard Links

**Creating Hard Links:**
```bash
# Create hard link
ln file1.txt file2.txt

# Check inode numbers
ls -li file1.txt file2.txt
```

**Characteristics:**
- Same inode number
- Same file content
- Both names are equally valid
- Deleting one doesn't delete the data

### Soft/Symbolic Links

**Creating Symbolic Links:**
```bash
# Create symbolic link
ln -s file1.txt file3.txt

# Check link
ls -l file3.txt
# file3.txt -> file1.txt
```

**Characteristics:**
- Different inode number
- Points to target path
- Can be broken (dangling)
- Takes very little space

**Use Cases:**
```bash
# Create shortcut to a directory
ln -s /usr/share/doc/ ~/docs

# Create shortcut for long path
ln -s /var/log/application/error.log ~/error.log
```

### Comparing Links

| Feature | Hard Link | Symbolic Link |
|---------|-----------|---------------|
| **Inode Number** | Same | Different |
| **Can Cross File Systems** | No | Yes |
| **Can Point to Directories** | No | Yes |
| **Dangling Possible** | No | Yes |
| **Space Used** | 0 (same file) | Very small |
| **Deleting Original** | File remains | Link breaks |

## Part 14: Command Line Shortcuts

### Prompt Customization (PS1)

The `PS1` variable controls the command prompt appearance.

**Common PS1 Elements:**

| Element | Meaning |
|---------|---------|
| `\u` | Username |
| `\h` | Hostname |
| `\w` | Full path |
| `\W` | Current directory only |
| `\$` | `$` for normal user, `#` for root |
| `\t` | Time |
| `\d` | Date |

**Example:**
```bash
# Custom prompt (username@host:path)
export PS1='\u@\h:\w\$ '

# Result: student@host:/home/student$
```

### Command History

**View History:**
```bash
# Show all history
history

# Show last N commands
history 20

# Re-run last command
!!

# Re-run command number N
!N

# Re-run last command starting with string
!ls
```

### Tab Completion

- Press **Tab** to auto-complete commands
- Press **Tab** twice to show options
- Works for commands, filenames, options

### Keyboard Shortcuts

| Shortcut | Action |
|----------|--------|

| `Ctrl+Z` | Suspend current command |
| `Ctrl+D` | Exit terminal |
| `Ctrl+L` | Clear screen |
| `Ctrl+A` | Go to beginning of line |
| `Ctrl+E` | Go to end of line |

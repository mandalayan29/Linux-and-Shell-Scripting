# User Environment: A Complete Tutorial Guide

## Introduction

Welcome to this comprehensive tutorial on the Linux user environment! This guide will teach you how to:

- Use and configure user accounts and user groups
- Use and set environment variables
- Use shell command history
- Use keyboard shortcuts
- Use and define aliases
- Set file permissions and ownership

Linux is a **multi-user operating system**, meaning more than one user can log on at the same time. Understanding the user environment is essential for effective system administration.

---

## Part 1: User and Group Management

### Identifying Users

```bash
# Show current user
whoami

# Show current user with more details
who am i

# List all logged-in users
who

# List all logged-in users with details
who -a
```

### Understanding Users and Groups

**User ID (UID):**
- Unique integer identifier for each user
- Normal users start with UID 1000 or greater
- System users have UIDs below 1000

**Group ID (GID):**
- Unique integer identifier for each group
- Primary group matches user's UID (by default)
- Users can belong to multiple groups

**Important Files:**

| File | Purpose |
|------|---------|
| `/etc/passwd` | User account information |
| `/etc/shadow` | Encrypted passwords |
| `/etc/group` | Group definitions |
| `/etc/skel/` | Default files for new users |
| `/etc/default/useradd` | Default user creation settings |

### Creating Users

#### useradd - Add User

**Syntax:**
```bash
useradd [options] username
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-m` | Create home directory |
| `-s` | Set default shell |
| `-c` | Add full name (comment) |
| `-g` | Specify primary group |
| `-G` | Specify supplementary groups |
| `-d` | Specify home directory |
| `-r` | Create system account |

**Examples:**
```bash
# Create user with default settings
sudo useradd username

# Create user with home directory
sudo useradd -m username

# Create user with specific shell
sudo useradd -m -s /bin/bash username

# Create user with full name
sudo useradd -m -c "Full Name" username

# On Ubuntu (creates home by default)
sudo useradd -m -s /bin/bash -c "Eric Dolphy" edolphy

# Set password for new user
sudo passwd edolphy
```

#### Default User Settings

```bash
# View default settings
useradd -D

# Default settings file
cat /etc/default/useradd
```

#### Setting User Password

```bash
# Set password for user
sudo passwd username

# Change your own password
passwd
```

### Removing Users

#### userdel - Delete User

**Syntax:**
```bash
userdel [options] username
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-r` | Remove home directory and mail spool |
| `-f` | Force removal |

**Examples:**
```bash
# Remove user (keep home directory)
sudo userdel username

# Remove user and home directory
sudo userdel -r username
```

### Modifying Users

#### usermod - Modify User

**Syntax:**
```bash
usermod [options] username
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-a` | Append to group (use with -G) |
| `-G` | Set supplementary groups |
| `-l` | Change login name |
| `-s` | Change shell |
| `-d` | Change home directory |

**Examples:**
```bash
# Change user's shell
sudo usermod -s /bin/zsh username

# Add user to group (append)
sudo usermod -a -G groupname username

# Change username
sudo usermod -l newname oldname
```

### Group Management

#### groupadd - Add Group

```bash
# Create new group
sudo groupadd groupname

# Create group with specific GID
sudo groupadd -g 2000 groupname
```

#### groupdel - Delete Group

```bash
# Delete group
sudo groupdel groupname
```

#### Adding/Removing Users from Groups

```bash
# Add user to group (append)
sudo usermod -a -G groupname username

# Remove user from group (must specify all groups)
sudo usermod -G group1,group2 username

# View user's groups
groups username

# Get detailed group information
id username
```

### Example: User Creation Workflow

```bash
# 1. Create user with home and shell
sudo useradd -m -s /bin/bash -c "Eric Dolphy" edolphy

# 2. Verify user was created
ls -la /home/edolphy

# 3. Set password
sudo passwd edolphy

# 4. Check user information
id edolphy
# uid=1001(edolphy) gid=1001(edolphy) groups=1001(edolphy)

# 5. Add user to additional groups
sudo usermod -a -G sudo edolphy
sudo usermod -a -G developers edolphy

# 6. Verify groups
groups edolphy
# edolphy : edolphy sudo developers

# 7. Test login
ssh edolphy@localhost

# 8. Remove user (when needed)
sudo userdel -r edolphy
```

## Part 2: The Root Account and Privilege Escalation

### Understanding Root

**Root is the Super User:**
- Full system access
- Can delete any file
- Can modify system settings
- Must be used with EXTREME caution

### su - Switch User

**Purpose:** Switch to another user account

**Syntax:**
```bash
su [options] [username]
```

**Examples:**
```bash
# Switch to root (requires root password)
su

# Switch to another user
su username

# Switch to root with environment
su -

# Run command as root
su -c "command"
```

**Problems with su:**
- Need to know root password
- Full root access (dangerous)
- No command logging

### sudo - Super User Do

**Purpose:** Run commands with elevated privileges

**Syntax:**
```bash
sudo [options] command
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-u` | Run as specific user |
| `-k` | Reset sudo timestamp |
| `-l` | List user's privileges |

**Examples:**
```bash
# Run command as root
sudo command

# Run command as another user
sudo -u username command

# Keep root shell
sudo -s

# List available sudo privileges
sudo -l
```

**Advantages of sudo:**
- Uses user's own password
- Can limit to specific commands
- Logs all commands
- More secure

### sudo Configuration

**Configuration Files:**
- `/etc/sudoers` - Main configuration (edit with `visudo`)
- `/etc/sudoers.d/` - Additional config files

**Adding sudo Access:**
```bash
# Edit sudoers file
sudo visudo

# Add user to sudo group (Debian/Ubuntu)
sudo usermod -a -G sudo username

# Add user to wheel group (RHEL/CentOS)
sudo usermod -a -G wheel username
```

**sudoers Entry Format:**
```
username ALL=(ALL) ALL
```

## Part 3: User Startup Files

### Startup File Overview

The shell (usually bash) uses startup files to configure the user environment.

```mermaid

    A[Login Shell] --> B[/etc/profile]
    B --> C[~/.bash_profile]
    B --> D[~/.bash_login]
    B --> E[~/.profile]
    
    F[Non-Login Shell] --> G[/etc/bash.bashrc]
    G --> H[~/.bashrc]
    
    style A fill:#f9f,stroke:#333,stroke-width:2px
    style F fill:#9f9,stroke:#333,stroke-width:2px
```

### Login Shells vs Non-Login Shells

| Shell Type | When Started | Files Read |
|------------|--------------|------------|
| **Login Shell** | System login, SSH login, `su -` | `/etc/profile`, `~/.bash_profile` |
| **Non-Login Shell** | Terminal window, `bash` command | `/etc/bash.bashrc`, `~/.bashrc` |

### Global vs User Settings

**Global Settings (System-wide):**
- `/etc/profile` - System-wide profile
- `/etc/bash.bashrc` - System-wide bashrc
- Applies to all users
- Only root can modify

**User Settings (Personal):**
- `~/.bash_profile` - Personal login settings
- `~/.bash_login` - Alternative login settings
- `~/.profile` - Login settings (fallback)
- `~/.bashrc` - Personal settings (every shell)
- Applies to specific user only

### Common Startup File Customizations

```bash
# ~/.bashrc - Add these for customizations

# Custom prompt
PS1='\u@\h:\w\$ '

# Aliases
alias ll='ls -la'
alias gs='git status'

# Environment variables
export EDITOR=nano
export PATH="$HOME/bin:$PATH"

# Set default shell options
shopt -s histappend
```

### Order of Execution (Login Shell)

1. `/etc/profile`
2. `~/.bash_profile` (if exists)
3. `~/.bash_login` (if exists)
4. `~/.profile` (if exists)

**Important:** The first file found is used; others are ignored.

## Part 4: Environment Variables

### What are Environment Variables?

**Environment variables** are character strings that contain information used by applications and the shell.

**Purpose:**
- Store configuration values
- Control program behavior
- Share data between processes

### Viewing Environment Variables

```bash
# View all environment variables
printenv

# View specific variable
echo $VARIABLE_NAME

# View all (including shell variables)
set

# Export all variables
export
```

### Common Environment Variables

| Variable | Purpose | Example |
|----------|---------|---------|
| **HOME** | User's home directory | `/home/username` |
| **PATH** | Directories to search for commands | `/usr/bin:/usr/local/bin` |
| **SHELL** | User's default shell | `/bin/bash` |
| **USER** | Current username | `username` |
| **PWD** | Current working directory | `/home/username/Documents` |
| **OLDPWD** | Previous working directory | `/home/username` |
| **TERM** | Terminal type | `xterm-256color` |
| **EDITOR** | Default text editor | `nano` |
| **HISTSIZE** | History size | `1000` |

### Setting Environment Variables

```bash
# Set variable for current shell (not inherited)
VARIABLE=value

# Set variable for current shell and child processes
export VARIABLE=value

# Set variable for a single command
VARIABLE=value command

# Append to PATH
export PATH="$PATH:/new/directory"

# Prepend to PATH
export PATH="/new/directory:$PATH"
```

### PATH Environment Variable

**Purpose:** Specifies directories to search for executables

**Order Matters:**
- Directories are searched left to right
- First match is used
- Empty directory (or `:`) means current directory

**View PATH:**
```bash
echo $PATH
```

**Add to PATH in .bashrc:**
```bash
# ~/.bashrc
export PATH="$HOME/bin:$PATH"
```

### PS1 - Prompt String

**Purpose:** Customize command prompt appearance

**Common PS1 Elements:**

| Code | Meaning |
|------|---------|
| `\u` | Username |
| `\h` | Hostname |
| `\w` | Full path |
| `\W` | Current directory only |
| `\$` | `$` for user, `#` for root |
| `\t` | Time (HH:MM:SS) |
| `\d` | Date |
| `\n` | Newline |

**Examples:**
```bash
# Simple prompt: user@host:path$
export PS1='\u@\h:\w\$ '

# With time: [14:30] user@host:path$
export PS1='[\t] \u@\h:\w\$ '

# Two-line prompt
export PS1='\u@\h:\w\n\$ '

# Color prompt (advanced)
export PS1='\[\033[01;32m\]\u@\h\[\033[00m\]:\[\033[01;34m\]\w\[\033[00m\]\$ '
```

## Part 5: Command History

### Viewing History

```bash
# Show entire history
history

# Show last N commands
history N

# Show history with timestamps
HISTTIMEFORMAT="%F %T " history
```

### Using History

```bash
# Re-run last command
!!

# Re-run command number N
!N

# Re-run last command starting with string
!string

# Re-run last command containing string
!?string?

# Re-run last command with substitution
^old^new
```

### History Search

**Reverse Search (Ctrl+R):**
1. Press **Ctrl+R**
2. Start typing part of command
3. Press **Ctrl+R** again for next match
4. Press **Enter** to execute
5. Press **Esc** to cancel

**Example:**
```
(reverse-i-search)`ap': sudo apt install vim
```

### History Environment Variables

| Variable | Purpose |
|----------|---------|
| `HISTSIZE` | Number of commands in memory |
| `HISTFILESIZE` | Maximum lines in history file |
| `HISTFILE` | Location of history file |
| `HISTCONTROL` | Control command saving |

**Examples:**
```bash
# Increase history size
export HISTSIZE=10000
export HISTFILESIZE=20000

# Don't save duplicate commands
export HISTCONTROL=ignoredups

# Don't save commands with spaces
export HISTCONTROL=ignorespace

# Save commands immediately
export PROMPT_COMMAND="history -a"
```

## Part 7: Aliases

### What are Aliases?

**Aliases** are shortcuts for longer commands. They make repetitive tasks faster.

### Creating Aliases

```bash
# Create alias
alias name='command'

# Create alias for common commands
alias ll='ls -la'
alias gs='git status'
alias update='sudo apt update && sudo apt upgrade'
```

### Viewing Aliases

```bash
# List all aliases
alias

# Show specific alias
alias name
```

### Removing Aliases

```bash
# Remove alias
unalias name

# Remove all aliases
unalias -a
```

### Making Aliases Permanent

Add aliases to `~/.bashrc`:

```bash
# ~/.bashrc
alias ll='ls -la'
alias la='ls -A'
alias l='ls -CF'
alias ..='cd ..'
alias ...='cd ../..'
alias grep='grep --color=auto'
alias update='sudo apt update && sudo apt upgrade'
alias c='clear'
```

### Alias Rules

- **No spaces** around the `=`
- Use quotes if the command has spaces
- Aliases only work in interactive shells
- Can be overridden by running `\command`

**Examples:**
```bash
# Good
alias ll='ls -la'

# Bad (spaces)
alias ll = 'ls -la'

# Override alias
\ls -la
```

## Part 8: File Permissions

### Understanding Permissions

**Three Permission Types:**

| Permission | File Meaning | Directory Meaning |
|------------|--------------|-------------------|
| **r (read)** | View file contents | List directory contents |
| **w (write)** | Modify file | Create/delete files |
| **x (execute)** | Run file | Enter directory |

**Three Ownership Classes:**

| Class | Symbol | Description |
|-------|--------|-------------|
| **Owner** | `u` | User who owns the file |
| **Group** | `g` | Group assigned to file |
| **Others** | `o` | Everyone else |

### Viewing Permissions

```bash
# Long listing shows permissions
ls -l

# Example output: -rw-r--r--
#          │││││││││
#          └┴┴┴┴┴┴┴┴── Others (r--)
#            │││││││└── Group (r--)
#            │││││└──── Owner (rw-)
#            ││││└────── Type (- file, d directory)
```

### Numeric (Octal) Permissions

**Permission Values:**

| Value | Permission |
|-------|------------|
| 4 | Read |
| 2 | Write |
| 1 | Execute |

**Common Permission Combinations:**

| Octal | Binary | Meaning |
|-------|--------|---------|
| 0 | 000 | No permissions |
| 1 | 001 | Execute only |
| 2 | 010 | Write only |
| 3 | 011 | Write + Execute |
| 4 | 100 | Read only |
| 5 | 101 | Read + Execute |
| 6 | 110 | Read + Write |
| 7 | 111 | Read + Write + Execute |

### chmod - Change Mode

**Purpose:** Change file permissions

**Syntax (Symbolic):**
```bash
chmod [who][operator][permissions] filename
```

**Symbolic Syntax Elements:**

| Who | Operator | Permission |
|-----|----------|------------|
| `u` | `+` add | `r` read |
| `g` | `-` remove | `w` write |
| `o` | `=` set | `x` execute |
| `a` | | `s` setuid/setgid |

**Syntax (Numeric):**
```bash
chmod [octal] filename
```

**Examples:**
```bash
# Symbolic
chmod u+x file        # Add execute for owner
chmod g-w file        # Remove write for group
chmod o+r file        # Add read for others
chmod u=rwx,g=rx,o=r file  # Set specific permissions
chmod a+x file        # Add execute for all

# Numeric
chmod 755 file        # rwxr-xr-x
chmod 644 file        # rw-r--r--
chmod 700 file        # rwx------
chmod 600 file        # rw-------
```

### chown - Change Owner

**Purpose:** Change file owner and group

**Syntax:**
```bash
chown [options] owner[:group] file
```

**Examples:**
```bash
# Change owner only
sudo chown username file

# Change owner and group
sudo chown username:groupname file

# Change group only
sudo chown :groupname file

# Change recursively
sudo chown -R username:groupname /path
```

### chgrp - Change Group

**Purpose:** Change group ownership

**Syntax:**
```bash
chgrp [options] groupname file
```

**Examples:**
```bash
# Change group
sudo chgrp developers file

# Change recursively
sudo chgrp -R developers /project
```

### Special Permissions

**setuid (set User ID):**
- Runs with owner's permissions
- `chmod u+s file`
- Numeric: 4000

**setgid (set Group ID):**
- Runs with group's permissions
- `chmod g+s file`
- Numeric: 2000

**Sticky Bit:**
- Only owner can delete files in directory
- `chmod +t directory`
- Numeric: 1000

**Examples:**
```bash
# Setuid
chmod u+s /usr/bin/passwd

# Setgid
chmod g+s shared_dir

# Sticky bit
chmod +t /tmp
```

## Part 9: Umask - Default Permissions

### What is umask?

**umask** determines default permissions for new files and directories.

**Calculation:**
- File default: 666 - umask
- Directory default: 777 - umask

### Viewing and Setting umask

```bash
# View current umask
umask

# Set umask
umask 022
```

**Common umask Values:**

| umask | File Permissions | Directory Permissions |
|-------|------------------|----------------------|
| 000 | 666 (rw-rw-rw-) | 777 (rwxrwxrwx) |
| 022 | 644 (rw-r--r--) | 755 (rwxr-xr-x) |
| 027 | 640 (rw-r-----) | 750 (rwxr-x---) |
| 077 | 600 (rw-------) | 700 (rwx------) |

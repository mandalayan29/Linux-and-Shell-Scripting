# Manipulating Text: A Complete Tutorial Guide

## Introduction

Welcome to this comprehensive tutorial on text manipulation in Linux! This guide will teach you how to:

- Display and append to file contents using `cat` and `echo`
- Edit and print file contents using `sed` and `awk`
- Search for patterns using `grep`
- Use multiple utilities for file and text manipulation

Whether you are a system administrator, developer, or user, you will often need to browse through and parse text files. Mastering these text manipulation tools is essential for efficient Linux usage.

---

## Part 1: Viewing File Contents

### cat - Concatenate Files

**Purpose:** Read and print files, combine multiple files

**Syntax:**
```bash
cat [options] [files]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-n` | Number all output lines |
| `-b` | Number non-blank lines |
| `-s` | Squeeze multiple blank lines |
| `-E` | Show line endings |

**Examples:**
```bash
# Display file contents
cat file.txt

# Display with line numbers
cat -n file.txt

# Combine multiple files
cat file1.txt file2.txt > combined.txt

# Create a file (Ctrl+D to finish)
cat > newfile.txt

# Append to a file
cat >> existingfile.txt
```

**Creating Files with cat:**
```bash
# Method 1: Type directly
cat > file.txt
Line 1
Line 2
Line 3
# Press Ctrl+D to finish

# Method 2: Using heredoc
cat > file.txt << EOF
Line 1
Line 2
Line 3
EOF
```

### tac - Reverse File Display

**Purpose:** Display file lines in reverse order (cat backwards)

**Syntax:**
```bash
tac [options] [file]
```

**Example:**
```bash
# Display file from last line to first
tac file.txt
```

### less - Page Through Files

**Purpose:** View large files page by page (without loading entire file into memory)

**Syntax:**
```bash
less [options] [file]
```

**Advantages over text editors:**
- Doesn't load entire file into memory
- Faster for large files
- Good for viewing log files

**Common Options:**

| Option | Description |
|--------|-------------|
| `-N` | Show line numbers |
| `-S` | Chop long lines (no wrap) |
| `-g` | Highlight last search |

**Navigation Keys:**

| Key | Action |
|-----|--------|
| **Space** | Next page |
| **b** | Previous page |
| **Enter** | Next line |
| **g** | Go to top |
| **G** | Go to bottom |
| **/pattern** | Search forward |
| **?pattern** | Search backward |
| **n** | Next match |
| **N** | Previous match |
| **q** | Quit |

### head - Display First Lines

**Purpose:** Display the first few lines of a file

**Syntax:**
```bash
head [options] [file]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-n N` | Show first N lines |
| `-c N` | Show first N bytes |

**Examples:**
```bash
# Show first 10 lines (default)
head file.txt

# Show first 20 lines
head -n 20 file.txt

# Show first 100 bytes
head -c 100 file.txt
```

### tail - Display Last Lines

**Purpose:** Display the last few lines of a file

**Syntax:**
```bash
tail [options] [file]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-n N` | Show last N lines |
| `-f` | Follow file (watch for changes) |
| `-F` | Follow with retry |
| `-c N` | Show last N bytes |

**Examples:**
```bash
# Show last 10 lines (default)
tail file.txt

# Show last 20 lines
tail -n 20 file.txt

# Monitor a growing log file (very useful!)
tail -f /var/log/syslog

# Show last 50 lines of a log
tail -n 50 /var/log/nginx/access.log
```

## Part 2: sed - Stream Editor

### What is sed?

**sed** (stream editor) is a powerful text processing tool used for filtering and transforming text.

**Key Features:**
- Modify file contents
- Filter text streams
- Perform substitutions
- Very lightweight and fast

### sed Basic Syntax

```bash
sed [options] 'command' [file]
sed -e 'command1' -e 'command2' [file]
sed -f script_file [file]
```

### sed Substitution Command

**Syntax:**
```bash
sed 's/pattern/replacement/[flags]' file
```

**Flags:**

| Flag | Description |
|------|-------------|
| `g` | Global (replace all occurrences) |
| `N` | Replace Nth occurrence |
| `p` | Print pattern space |
| `w file` | Write to file |

### sed Examples

```bash
# Basic substitution (first occurrence only)
sed 's/is/Was/' file.txt

# Replace all occurrences (global)
sed 's/is/Was/g' file.txt

# Replace on specific lines (lines 1-2)
sed '1,2s/is/Was/g' file.txt

# Use different delimiter (useful for paths)
sed 's:/usr/local:/opt:g' file.txt

# Replace and save to new file
sed 's/old/new/g' input.txt > output.txt

# Delete lines containing pattern
sed '/pattern/d' file.txt

# Print only lines matching pattern
sed -n '/pattern/p' file.txt

# Insert text before/after a line
sed '/pattern/i\Insert this line' file.txt
sed '/pattern/a\Append this line' file.txt
```

### sed Demonstration

```bash
# Create sample file
cat > sample.txt << EOF
This is line one
This is line two
This is line three
EOF

# Replace first occurrence on each line
sed 's/is/Was/' sample.txt

# Replace all occurrences
sed 's/is/Was/g' sample.txt

# Replace only on lines 1-2
sed '1,2s/is/Was/g' sample.txt

# Use different delimiter
sed 's:is:Was:g' sample.txt

# Save to new file
sed 's/is/Was/g' sample.txt > output.txt

# Check differences
diff sample.txt output.txt
```

### sed - In-Place Editing

**Warning:** This modifies the original file!

```bash
# Backup then edit in place
sed -i.bak 's/old/new/g' file.txt

# Edit in place (no backup)
sed -i 's/old/new/g' file.txt
```

## Part 3: awk - Text Processing

### What is awk?

**awk** is a powerful text processing language used for:
- Extracting data
- Creating reports
- Processing text files
- Pattern scanning

### awk Basic Syntax

```bash
awk [options] 'pattern {action}' [file]
awk -F separator 'pattern {action}' [file]
awk -f script_file [file]
```

### awk Basic Structure

```
awk 'BEGIN { initialization } pattern { action } END { finalization }' file
```

### awk Examples

```bash
# Print entire file
awk '{print}' file.txt

# Print specific fields
awk '{print $1, $3}' file.txt

# Print with custom separator
awk -F: '{print $1, $3}' /etc/passwd

# Print lines matching pattern
awk '/pattern/ {print}' file.txt

# Print lines where field matches
awk '$3 > 1000 {print}' file.txt

# Count lines
awk 'END {print NR}' file.txt

# Sum a column
awk '{sum += $1} END {print sum}' file.txt

# Print with formatted output
awk '{printf "%-10s %-10s\n", $1, $2}' file.txt
```

### awk Demonstration

```bash
# Sample file
cat > employees.txt << EOF
John Smith 50000
Jane Doe 60000
Bob Johnson 45000
Alice Williams 55000
EOF

# Print name and salary
awk '{print $1, $3}' employees.txt

# Print employees making > 50000
awk '$3 > 50000 {print $1, $3}' employees.txt

# Print with label
awk '{print "Name: " $1 ", Salary: $" $3}' employees.txt

# Sum all salaries
awk '{sum += $3} END {print "Total: $" sum}' employees.txt

# Print employee count
awk 'END {print "Employees: " NR}' employees.txt
```

### awk with /etc/passwd

```bash
# Print usernames and shells
awk -F: '{print $1, $7}' /etc/passwd

# Print users with /bin/bash shell
awk -F: '$7 == "/bin/bash" {print $1}' /etc/passwd

# Print UID > 1000
awk -F: '$3 > 1000 {print $1, $3}' /etc/passwd

# Print with header
awk -F: 'BEGIN {print "User\tShell"} {print $1 "\t" $7}' /etc/passwd
```

## Part 4: grep - Pattern Searching

### What is grep?

**grep** is the primary text searching tool on Linux. It scans files for specified patterns.

**Name Origin:** `grep` = **g**lobal **r**egular **e**xpression **p**rint

### grep Syntax

```bash
grep [options] pattern [file]
grep [options] pattern file1 file2 ...
```

### Common grep Options

| Option | Description |
|--------|-------------|
| `-i` | Case insensitive |
| `-v` | Invert match (exclude pattern) |
| `-n` | Show line numbers |
| `-c` | Count matches |
| `-l` | Show only filenames |
| `-r` | Recursive search |
| `-E` | Extended regular expressions |
| `-A N` | Show N lines after match |
| `-B N` | Show N lines before match |
| `-C N` | Show N lines before and after |

### grep Examples

```bash
# Simple search
grep "pattern" file.txt

# Case insensitive
grep -i "pattern" file.txt

# Show line numbers
grep -n "pattern" file.txt

# Count matches
grep -c "pattern" file.txt

# Exclude lines with pattern
grep -v "pattern" file.txt

# Recursive search
grep -r "pattern" /path/

# Search multiple files
grep "pattern" file1.txt file2.txt

# Show surrounding lines
grep -A 2 -B 2 "pattern" file.txt
```

### grep with Regular Expressions

```bash
# Lines starting with pattern
grep "^pattern" file.txt

# Lines ending with pattern
grep "pattern$" file.txt

# Lines containing numbers
grep "[0-9]" file.txt

# Lines containing word (whole word)
grep -w "word" file.txt

# Lines with either pattern
grep -E "pattern1|pattern2" file.txt

# Extended regex (simpler syntax)
grep -E "pat{2}" file.txt  # matches patt
```

### Practical grep Usage

```bash
# Find all .conf files containing "ServerName"
grep -r "ServerName" /etc/apache2/

# Find errors in log files
grep "ERROR" /var/log/*.log

# Find users in /etc/passwd
grep "/bin/bash" /etc/passwd

# Find running processes
ps aux | grep "nginx"

# Find installed packages
dpkg -l | grep "nginx"

# Count occurrences in a file
grep -c "error" logfile.txt

# Show lines with errors and context
grep -C 3 "FATAL" logfile.txt
```

### grep and Strings

**strings** extracts printable character strings from binary files:

```bash
# Find text in binary file
strings binary_file | grep "pattern"

# Search for GPL in binary programs
strings /bin/ls | grep GPL
```

## Part 5: File Manipulation Utilities

### sort - Sort File Contents

**Purpose:** Rearrange lines in ascending or descending order

**Syntax:**
```bash
sort [options] [file]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-r` | Reverse order |
| `-n` | Numeric sort |
| `-k N` | Sort by field N |
| `-t C` | Field separator C |
| `-u` | Unique sort |
| `-f` | Ignore case |

**Examples:**
```bash
# Alphabetical sort
sort file.txt

# Reverse sort
sort -r file.txt

# Numeric sort
sort -n file.txt

# Sort by second field
sort -k2 file.txt

# Sort with custom separator
sort -t: -k3 -n /etc/passwd

# Sort and remove duplicates
sort -u file.txt
```

### uniq - Remove Duplicate Lines

**Purpose:** Remove duplicate consecutive lines

**Note:** Input must be sorted first (or use `sort -u`)

**Syntax:**
```bash
uniq [options] [file]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-c` | Count occurrences |
| `-d` | Show only duplicates |
| `-u` | Show only unique |

**Examples:**
```bash
# Remove duplicates (requires sorted input)
sort file.txt | uniq

# Count occurrences
sort file.txt | uniq -c

# Show only duplicates
sort file.txt | uniq -d

# Show only unique lines
sort file.txt | uniq -u

# One step sort and unique
sort -u file.txt
```

### paste - Combine Files

**Purpose:** Merge lines from multiple files

**Syntax:**
```bash
paste [options] file1 file2
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-d` | Specify delimiter |
| `-s` | Serial (vertical) paste |

**Examples:**
```bash
# Paste two files side by side
paste file1.txt file2.txt

# Use comma as delimiter
paste -d, file1.txt file2.txt

# Serial paste (all from file1, then file2)
paste -s file1.txt file2.txt
```

### join - Join Files on Common Field

**Purpose:** Combine files based on a common field

**Syntax:**
```bash
join [options] file1 file2
```

**Examples:**
```bash
# Join on first field (default)
join file1.txt file2.txt

# Join on specific field
join -1 2 -2 3 file1.txt file2.txt
```

### split - Split Files

**Purpose:** Break large files into smaller segments

**Syntax:**
```bash
split [options] file [prefix]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-l N` | Split into N-line segments |
| `-b SIZE` | Split into SIZE-byte segments |

**Examples:**
```bash
# Split into 1000-line files
split file.txt

# Split into 100-line files with prefix
split -l 100 file.txt part_

# Split into 1MB files
split -b 1M file.txt part_
```

## Part 6: Other Text Utilities

### echo - Display Text

**Purpose:** Display a line of text

**Syntax:**
```bash
echo [options] [text]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-n` | Don't output newline |
| `-e` | Enable escape sequences |

**Examples:**
```bash
# Simple output
echo "Hello, World!"

# Without newline
echo -n "Hello"

# With escape sequences
echo -e "Line 1\nLine 2\tTabbed"
```

### tr - Translate Characters

**Purpose:** Translate or delete characters

**Syntax:**
```bash
tr [options] set1 [set2]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-d` | Delete characters in set1 |
| `-s` | Squeeze duplicates |

**Examples:**
```bash
# Convert lowercase to uppercase
cat file.txt | tr 'a-z' 'A-Z'

# Convert uppercase to lowercase
cat file.txt | tr 'A-Z' 'a-z'

# Delete specific characters
cat file.txt | tr -d 'aeiou'

# Squeeze spaces
cat file.txt | tr -s ' '
```

### tee - Split Output

**Purpose:** Write output to both file and terminal

**Syntax:**
```bash
command | tee [options] file
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-a` | Append to file |

**Examples:**
```bash
# Save output while viewing
ls -la | tee output.txt

# Append to file
ls -la | tee -a output.txt
```

### wc - Word Count

**Purpose:** Count lines, words, and characters

**Syntax:**
```bash
wc [options] [file]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-l` | Count lines |
| `-w` | Count words |
| `-c` | Count characters |
| `-m` | Count characters (multi-byte) |

**Examples:**
```bash
# Count all (lines, words, chars)
wc file.txt

# Count only lines
wc -l file.txt

# Count only words
wc -w file.txt

# Count characters
wc -c file.txt
```

### cut - Extract Columns

**Purpose:** Extract specific fields from files

**Syntax:**
```bash
cut [options] [file]
```

**Common Options:**

| Option | Description |
|--------|-------------|
| `-f LIST` | Select fields |
| `-d C` | Set delimiter |
| `-c LIST` | Select character positions |

**Examples:**
```bash
# Extract field 1 (tab delimiter)
cut -f1 file.txt

# Extract field 3 with comma delimiter
cut -d, -f3 file.txt

# Extract multiple fields
cut -f1,3 file.txt

# Extract character positions
cut -c1-10 file.txt
```

## Part 7: Regular Expressions

### What are Regular Expressions?

**Regular expressions** are text strings used for:
- Matching specific patterns
- Searching for specific locations (start/end of line/word)
- Pattern matching in utilities like `grep`, `sed`, `awk`, `vim`

### Basic Regular Expression Characters

| Character | Meaning | Example |
|-----------|---------|---------|
| `.` | Any single character | `c.t` matches "cat", "cut" |
| `^` | Beginning of line | `^start` matches lines starting with "start" |
| `$` | End of line | `end$` matches lines ending with "end" |
| `*` | Zero or more | `a*` matches "", "a", "aa", "aaa" |
| `+` | One or more (extended) | `a+` matches "a", "aa", "aaa" |
| `?` | Zero or one (extended) | `a?` matches "" or "a" |
| `[abc]` | Any of these characters | `[abc]` matches a, b, or c |
| `[^abc]` | Any except these | `[^abc]` matches any char except a,b,c |
| `[0-9]` | Any digit | `[0-9]` matches 0-9 |
| `[a-z]` | Any lowercase | `[a-z]` matches a-z |
| `\` | Escape character | `\.` matches literal "." |

### Extended Regular Expressions (grep -E)

| Character | Meaning | Example |
|-----------|---------|---------|
| `|` | OR | `cat|dog` matches "cat" or "dog" |
| `()` | Group | `(abc)+` matches "abcabc" |
| `{N}` | Exactly N times | `a{3}` matches "aaa" |
| `{N,}` | N or more | `a{2,}` matches "aa", "aaa" |
| `{,M}` | Up to M times | `a{,3}` matches "", "a", "aa", "aaa" |
| `{N,M}` | Between N and M | `a{2,4}` matches "aa", "aaa", "aaaa" |

### Regular Expression Examples

```bash
# Lines starting with "The"
grep "^The" file.txt

# Lines ending with "end"
grep "end$" file.txt

# Lines containing any digit
grep "[0-9]" file.txt

# Lines with 3-digit numbers
grep "[0-9][0-9][0-9]" file.txt

# Lines with "cat" or "dog"
grep -E "cat|dog" file.txt

# Lines with repeated letters
grep -E "a{2,}" file.txt

# Lines with any single character between c and t
grep "c.t" file.txt

# Lines not containing "pattern"
grep -v "pattern" file.txt
```

## Part 8: Text Manipulation Workflows

### Common Pipelines

```bash
# Count unique errors in log
grep "ERROR" log.txt | sort | uniq -c | sort -rn

# Find largest files
find . -type f -exec ls -s {} \; | sort -rn | head -10

# Count log entries by IP
grep "Failed" /var/log/auth.log | awk '{print $11}' | sort | uniq -c

# Extract and format data
cat employees.txt | awk '{print $1, $3}' | sort -k2 -rn
```

### Example: System Monitoring Workflow

```bash
# Monitor SSH login attempts
tail -f /var/log/auth.log | grep "sshd"

# Check top memory users
ps aux | sort -nrk 4 | head -10

# Check disk usage
df -h | awk '{print $5 " " $6}' | sort -rn | head -10

# Find large files in home directory
find ~ -type f -size +100M -exec ls -lh {} \; | sort -k5 -h
```

### Example: Log Analysis

```bash
# Analyze web server logs
# Count unique IP addresses
cat access.log | awk '{print $1}' | sort | uniq -c | sort -rn

# Top 10 requested pages
cat access.log | awk '{print $7}' | sort | uniq -c | sort -rn | head -10

# Error responses
grep " 404 " access.log | awk '{print $1}' | sort | uniq -c
```
